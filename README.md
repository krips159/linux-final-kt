# Task Manager

Небольшой TUI-проект на Bash для управления списком задач в терминале.

## О проекте

Task Manager позволяет добавлять, просматривать, искать, подсчитывать и удалять задачи.

Проект создан в рамках итоговой работы по Linux и Bash.

## Возможности

Программа имеет следующие пункты меню:

1. Добавить задачу
2. Показать задачи
3. Найти задачу
4. Посчитать задачи
5. Удалить задачу
6. Выход

## Структура проекта

```text
bash-tui-project/
├── app.sh
├── README.md
├── data/
│   └── tasks.txt
└── reports/
```

### Файлы

* `app.sh` — основной Bash-скрипт.
* `data/tasks.txt` — файл с задачами.
* `README.md` — описание проекта.
* `reports/` — папка для отчётов и дополнительных материалов.

## Запуск

Перейти в папку проекта:

```bash
cd ~/bash-tui-project
```

Выдать право на выполнение:

```bash
chmod +x app.sh
```

Запустить программу:

```bash
./app.sh
```

## Хранение данных

Все задачи хранятся в файле:

```text
data/tasks.txt
```

При добавлении новой задачи она записывается в конец файла.
